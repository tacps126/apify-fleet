# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, welcome newcomers, give and take feedback gracefully, and focus on what is best
for the people using the project. Harassment, insults and personal attacks are not tolerated.

Report unacceptable behaviour by opening a private security advisory on GitHub
(Security tab, "Report a vulnerability") or by contacting the maintainers listed on the repository.
Reports are handled confidentially.
